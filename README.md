# Yufo Trickster

Portfolio website for **Yufo Trickster**: handstand instructor, contortionist, B-boy and brand ambassador athlete. Visitors can browse the portfolio and book one-on-one classes, workshops and live performances.

## Tech Stack

- Static site: HTML, CSS and vanilla JavaScript
- No build step or dependencies

## Project Structure

```
├── index.html            # Main page
├── css/modern.css        # Site styles
├── js/modern.js          # Site behavior
├── js/portfolio-data.js  # Portfolio entries
├── images/, img/         # Image assets
└── favicon.ico
```
